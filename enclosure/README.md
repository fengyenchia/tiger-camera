# Enclosure

V1 外殼是可拆修的基本矩形相機，不做虎頭、角色裝飾、喇叭或音孔。

## 開始條件

外殼 CAD 要等 Gate P0 通過後再鎖定。先以卡尺量測：

- ESP32-S3-CAM PCB、鏡頭高度與兩個 USB-C 開口
- ST7735 PCB、可視區、排針與實際對角尺寸
- 快門、按鍵帽與行程
- LiPo 長寬厚、導線、接頭與保護板
- 充電升壓模組、電感、USB 充電口與 LED
- 電源開關與 JST 接頭
- NFC 貼紙

## 佈局原則

- 螢幕直式、鏡頭正視，符合已驗證的顯示與照片方向。
- 電池可拆換並保留膨脹空間；螺絲、柱位與銳角不得壓向電芯。
- 升壓模組與電池避開 ESP32 天線淨空區。
- 充電孔、開關、NFC 與快門可從外部操作。
- 保留線材彎曲半徑、熱縮管、散熱與維修空間。
- 先印平面定位板與孔徑測試片，再做兩片式功能殼。

P0 接線與安全要求見 [`../docs/hardware.md`](../docs/hardware.md)。
