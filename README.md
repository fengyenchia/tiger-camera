# Tiger Camera

一台以虎頭為造型、以方形螢幕作為虎嘴的小型玩具相機。

短按快門後，裝置會拍攝並保存 JPEG，螢幕立即顯示照片與一則隨機小虎文字；手機連上相機建立的 Wi‑Fi 後，可在區域網站套用高品質復古效果並下載原圖或完成圖。

> 目前狀態：規劃完成，尚未採購與實作。
> 規格基準日：2026-08-02。

## V1 範圍

- XIAO ESP32S3 Sense 與原廠相機
- 1.3 吋、240 × 240、ST7789 方形 IPS
- 實體快門，短按拍照
- 拍後回看時隨機顯示玩具感文字
- JPEG 原圖寫入板載 microSD 卡槽
- 拍後回看與低電量／充電提示
- 相機建立 2.4 GHz Wi‑Fi 熱點
- Captive Portal、mDNS 名稱與備援 IP
- 手機網頁使用 Canvas 做復古後製
- 原圖與完成 JPEG 下載
- 3D 列印虎頭外殼

GIF 不列入 V1，保留在待做清單。

## 開工前最重要的驗證

Sense 的板載 microSD 與 ST7789 都需要 SPI。V1 預計共用 SCK／MOSI，使用不同 CS，並以小型整合測試先證明「相機＋SD＋螢幕」能穩定同時工作。若不穩，才改用軟體 SPI 或調整硬體。

## 預算結論

- 僅成品必要零件：約 **NT$1,200～2,200**
- 含運費、備品與耗材的實際安全預算：約 **NT$2,000～3,000**
- 若焊接工具、麵包板等都沒有：再預留約 **NT$500～1,200**

不要一次買齊。先買主板、microSD、螢幕與按鍵，通過核心整合測試後，再買電池與外殼材料。
