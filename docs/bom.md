# BOM 與採購說明

唯一可計算、可更新的採購清單是 [`../bom/tiger-camera-v1.csv`](../bom/tiger-camera-v1.csv)。本頁只說明採購順序與風險，不另做第二份價格表。

## 已有核心

- AroundTW／GOOUUU ESP32-S3-CAM N16R8＋OV2640。
- ST7735 SPI 實機解析度已確認為 `128x128`；賣場共用標題曾寫成 128×160，不能拿來當實機規格。實際吋數與 PCB 尺寸仍以卡尺量測。
- GPIO1 快門、麵包板／杜邦線。
- NTAG215 被動 NFC 貼紙，尚待寫入及驗收。

## 下一批：P0 電源

建議同一批購買：

1. 帶保護板的單節 3.7V LiPo；目前選用 803040 1000mAh（8.0±0.3 × 30±0.5 × 40±1 mm）。商品規格：標準充電 0.5C／500mA、最大充電 1C／1A、最大放電 1C／1A；保護 IC 允許最大電流 2A。
2. 環島科技 TP4056 Type-C 1A 充電保護板；先採商品預設 1A，不修改電阻，首次量測確認不超過電池最大 1A 且溫度正常。
3. 環島科技 MT3608 2A 可調升壓板；輸出先調為 5.0V。
4. 電源開關（切斷 MT3608 輸入）。
5. 適合線徑的導線、熱縮管與絕緣膠帶；電池線採直焊，不另購 JST-PH 2.0。

下單前確認：

- 電池長寬厚、接頭型號、導線極性、保護板與允許充電電流。
- TP4056 實際充電電流是否約 1A 且不超過電池最大值；若發熱過高再改用預設 500mA 版本。
- MT3608 空載輸出是否能穩定調到 5.0V，以及接上相機、螢幕、Wi-Fi 時的負載壓降。
- 開關額定值高於相機、TFT 與 Wi-Fi 同時工作的實測峰值。

模組接線與安全流程見 [`hardware.md`](hardware.md)，驗收表見 [`test-plan.md`](test-plan.md)。

## 暫時不買

- microSD：V1 原圖存雲端、裝置只保留 PSRAM 最新 JPEG。
- 喇叭／擴大器：虎叫聲功能已取消。
- 虎頭裝飾與複雜外殼材料：V1 使用基本矩形外殼。
- 精確電量顯示零件：P0 先用充電模組 LED；若日後真的需要百分比再選 fuel gauge。

## 外殼批次

P0 通過並量完尺寸後，才買 M2 五金、PETG／代印與選配透明保護片。先印定位板與孔徑測試片，再印完整殼。
