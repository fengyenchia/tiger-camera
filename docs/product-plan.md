# Product Plan

## V1 產品

Tiger Camera 是基本矩形外殼的小型數位相機，不再製作老虎造型、喇叭或虎叫聲。短按快門後顯示剛拍的照片，不顯示隨機文字；裝置只暫存最新 JPEG，下一次成功拍照直接覆蓋。

## 使用者流程

1. 相機連接設定好的 2.4 GHz 手機熱點或可信任 Wi-Fi。
2. 使用者短按快門，裝置以固定 XGA 拍照並顯示回顧。
3. 背景工作把原圖上傳為私人草稿；成功後在 TFT 顯示 6 位領取碼。
4. 使用者掃描機身 NFC，開啟 `https://tiger-camera.fengyenchia.com/create`。
5. 輸入領取碼後，在自己的手機選擇拍立得框、日期、文字、濾鏡與基本影像調整；也可以全部關閉。
6. 使用者可下載完成圖，並自行決定是否公開到相簿。
7. 公開成功後自動進入公開相簿；所有人可查看，只有管理員可一次永久刪除。

## 保存規則

- 裝置：PSRAM 只保留最新 JPEG，重開機後可消失。
- R2 original：私人、暫時，只供 claim holder 後製；發布或逾期後刪除。
- R2 processed：完成圖；公開與否由領取者決定。
- Neon：保存 draft、claim token hash、狀態與相簿 metadata。
- microSD 非 V1 必需品。

## 隱私與權限

- 6 位碼只是方便配對，不是高安全密碼；首次成功領取即失效，24 小時到期。
- Claim 使用資料庫型 opaque UUID Bearer token，只能操作對應草稿。
- 單一相機使用固定高熵 `DEVICE_UPLOAD_TOKEN` 建立與完成草稿；同一值只存在 Backend environment 與韌體 secrets，可透過同步更換兩端進行輪替。Wi-Fi 不是 API 驗證，因此不開放匿名上傳。
- Admin JWT 才能刪除公開照片。
- 未公開的照片不得出現在公開列表。

## 電源版本

原型先用 USB 供電。下一階段外接帶保護的單節 3.7V LiPo 與 5V 充電／保護／升壓模組，再經實體開關接主板 5V。P0 必須實測上傳峰值、溫升、低壓截止、充電與續航後，才能進入外殼。

V1 初版只顯示模組提供的充電 LED，不承諾沒有量測電路的電量百分比。詳細流程見 [`hardware.md`](hardware.md)。

## 不在 V1

- GIF／錄影
- 公開註冊與社群功能
- Bluetooth 傳圖或原生 App
- AI 濾鏡與社群自動上傳
- 裝置端多照片相簿
- 虎造型、喇叭與隨機文字

## 成功條件

- 不依賴 microSD 也能拍照、回看、上傳與領取。
- Wi-Fi 失敗不影響基本拍照；恢復後可重試。
- 手機可完成高解析 Canvas 後製與下載。
- 私人、claim、公開與管理員權限沒有越界。
- 電池版無 brownout、異常發熱、回灌或電芯擠壓風險。
