# Tiger Camera V1 完整產品規劃

## 1. 產品定義

Tiger Camera 是專案暫名；成本版 V1 改成基本矩形相機外殼，不製作虎頭、虎嘴或其他角色結構。拍照成功後，小型彩色螢幕顯示最新照片與一則隨機文字。最新 JPEG 只暫存在裝置 PSRAM，正式復古後製交由手機瀏覽器處理；原圖與後製圖可永久保存到 `tiger-camera.fengyenchia.com` 的私人相簿。

一句話版本：

> 按下相機快門，螢幕立即回看最新照片；手機取得照片並完成復古後製後，可下載到手機或永久保存到私人網站。

## 2. 設計目標

1. **先省硬體成本**：基本外殼、拍後回看與隨機文字取代複雜角色結構。
2. **可完成**：ESP32 只做擅長的拍攝、儲存、顯示與區域傳輸；複雜後製放到手機。
3. **離線核心可用**：沒有網際網路時仍能拍照、回看、取得及下載最新照片；永久相簿需要管理員登入與網際網路。
4. **保留原圖**：任何濾鏡都不覆寫 JPEG 原始照片。
5. **私人永久保存**：原圖與後製圖分開保存，只有管理員可以查看與刪除。
6. **先證明核心技術，再做漂亮外殼**。

## 3. 主要使用者流程

### 3.1 拍照

1. 長按電源或喚醒按鍵啟動。
2. 小型螢幕顯示即時預覽。
3. 使用者短按實體快門。
4. 裝置鎖定畫面並拍攝 JPEG。
5. 將相機 framebuffer 複製到裝置持有的 PSRAM buffer，再歸還相機 framebuffer。
6. 複製成功後，螢幕顯示剛拍的照片與一則隨機文字 3～5 秒。
7. 回到即時預覽。

目標體感：

- 從按下快門到畫面凍結：小於 300 ms。
- 從按下快門到可看到成品預覽：小於 2 秒。
- buffer 配置或複製失敗時不得假裝成功，必須顯示明確提示。
- 隨機文字只在最新 JPEG 複製完成後顯示；失敗時改顯示錯誤訊息。

V1 拍照成功文字池：

- `ROAR!`
- `抓到你了！`
- `虎視眈眈！`
- `今日獵物 +1`
- `小虎拍到了！`

抽選應近似均勻；同一句不得連續出現兩次。文字應加描邊、底色或陰影，確保在明暗照片上都可讀。

### 3.2 手機取圖與後製

1. 手機連接相機 Wi‑Fi：`TIGER-CAMERA`。
2. 系統嘗試自動開啟 Captive Portal。
3. 未自動開啟時，使用者進入 `http://camera.local`。
4. 備援入口為 `http://192.168.4.1`。
5. 手機可感應 NTAG213／NTAG215 被動貼紙，開啟 `http://192.168.4.1/latest.jpg`；手機必須已連上相機 Wi‑Fi。
6. 網站顯示最新照片；尚未拍照時顯示清楚提示。
7. 使用者挑選四款效果之一，手機以 Canvas 合成復古色調、暗角、顆粒、拍攝日期與拍立得邊框。
8. 使用者可先下載完成 JPEG 或最新原圖；此功能不依賴雲端成功。

### 3.3 永久保存與管理

1. 瀏覽器保留原始 JPEG Blob，並另外產生後製 JPEG Blob。
2. 兩份 Blob 先進入瀏覽器待傳佇列，避免網路切換時立即遺失。
3. 管理員登入 `https://tiger-camera.fengyenchia.com`。
4. 網站向伺服器要求短效、限定照片 ID 與路徑的上傳網址。
5. 瀏覽器直接上傳原圖與後製圖，再通知 API 完成。
6. 只有伺服器確認兩份物件與 metadata 完整後，畫面才顯示「已永久保存」。
7. 相簿按一次刪除後直接永久刪除照片；V1 不設垃圾桶、還原或確認視窗。
8. 上傳失敗時保留待傳狀態，提供重試與下載到手機；不得假裝已保存。

### 3.4 網址的正確定位

- `camera.local` 是連上相機 Wi‑Fi 後可使用的 mDNS 名稱，不是公開網站。
- Captive Portal 會攔截一般 HTTP 導覽並帶到相機首頁。
- `http://192.168.4.1/latest.jpg` 是 NFC 與區域取圖的固定備援入口。
- `https://tiger-camera.fengyenchia.com` 是公開可到達、需要登入的雲端相簿，不是相機的區域網址。
- V1 不承諾相機端 HTTPS。管理員密碼、session 與雲端 API 只出現在公開 HTTPS 網站，不送到 ESP32。
- 公開 HTTPS 網站直接讀取區域 HTTP 裝置可能受瀏覽器 Local Network Access 與 mixed-content 規則限制，因此「區域頁面下載→公開網站選檔上傳」是必要備援。

## 4. 功能範圍

### 4.1 V1 必做

- 即時相機預覽
- 單一實體快門短按拍照
- 最新 JPEG 複製並暫存在 PSRAM
- 拍後回看
- 拍後回看時從 5 句文字中隨機顯示一句
- 1.44 吋 128 × 128 或 1.8 吋 128 × 160 ST7735 SPI 螢幕
- Wi‑Fi AP 與 Captive Portal
- 最新照片頁與 NFC 固定網址
- 四種手機端復古效果
- 拍攝日期、拍立得邊框、顆粒、暗角
- 原圖／完成 JPEG 下載
- `tiger-camera.fengyenchia.com` 管理員登入
- 私人儲存空間分開保存原圖與後製圖
- 照片 metadata、相簿列表與單次操作直接永久刪除
- 短效限定路徑上傳網址；長期儲存密鑰只留在伺服器
- 無網路待傳／重試狀態與手動選檔上傳備援
- USB 供電；電池版另以實測確認充電、保護與穩定 5 V 升壓
- 電池版的充電狀態提示；不承諾未量測的百分比電量
- 基本矩形 3D 列印相機外殼
- 錯誤狀態：尚無照片、記憶體不足、拍攝失敗、低電量

### 4.2 V1 明確不做

- GIF 或影片
- 觸控螢幕
- Bluetooth 傳照片
- 專屬手機 App
- 公開註冊與多使用者帳號
- AI 濾鏡
- 相機端高解析度後製
- 自動上傳社群
- 多台相機互傳
- microSD 裝置端永久保存、裝置端 JSON metadata 與裝置端多照片相簿

### 4.3 待做清單

- 長按快門進行 2～3 秒動態連拍
- 手機端合成與下載 GIF
- 更多濾鏡與手動參數
- microSD 裝置端離線備份與 JSON metadata
- OTA 無線更新
- 更完整的休眠與喚醒
- 多使用者帳號與分享權限

## 6. 資料、保存與隱私

V1 預設是「有 Wi‑Fi 密碼的共享最新照片」：

- 任何連上 `TIGER-CAMERA` 的人都可能看到目前最新照片。
- Wi‑Fi 使用 WPA2 密碼，不使用公開無密碼熱點。
- 拍下一張新照片會取代上一張；關機會清除照片。
- 網站清楚顯示「目前為區域共享最新照片」。

NFC 貼紙只保存固定網址，不保存照片或密碼，也不會自動把手機加入 Wi‑Fi。展示時仍需提供 Wi‑Fi 連線說明。

雲端相簿採不同安全邊界：

- 只有管理員登入後才能列出、讀取、上傳或刪除照片。
- 原圖與後製圖使用不同且不可覆寫的物件路徑。
- 瀏覽器與韌體不得持有資料庫密碼或長期物件儲存密鑰。
- 照片預設為 `active`；使用者按一次刪除即改為 `deleting` 並直接進入永久刪除流程。
- 永久刪除必須移除原圖、後製圖與 metadata；部分失敗時保留 `deleting` 狀態供重試，不留下無法追蹤的孤兒檔案。

## 7. 成功指標

### 功能驗收

- 連續拍 30 張，最新 buffer 每次都能被正確取代並讀取。
- 重新開機後清楚顯示尚無照片，不宣稱永久保存。
- Android Chrome、iPhone Safari、桌面 Chrome 均可進站與下載最新照片。
- 四款效果輸出方向、日期與顏色正確。
- 尚無照片、記憶體不足、相機錯誤與低電量都有可理解提示。
- 測試 JPEG 能完成「上傳→相簿→單次永久刪除」。
- 未登入者不能列出或讀取私人照片。
- 斷網上傳不會顯示成功，恢復網路後可重試或用手動選檔備援。

### 體驗驗收

- 第一次使用者在沒有口頭教學時，2 分鐘內完成「連 Wi‑Fi→找到照片→後製→下載」。
- 五句拍照成功文字都能出現，且不連續重複同一句。
- 手持時不遮鏡頭、天線與實際 USB 接口。

## 9. 目前尚未鎖死的決策

以下必須由實測決定，不在紙上假定：

1. 賣家 pinout 的 GPIO47／21／14 是否能穩定連接 ST7735，GPIO1 是否適合快門。
2. OTG 與 TTL 兩個 USB-C 在目標 PlatformIO 環境的燒錄與序列埠行為。
3. 所謂鋰電池底板是否真的同時包含充電、保護及 5 V 升壓。
4. 最終外殼尺寸與鏡頭／螢幕相對位置。
5. 五句回饋文字在 128 × 128／128 × 160 畫面上的最終字級與排版。
6. iOS 與 Android 的 Captive Portal 行為。
7. 目標 iPhone／Android 對公開 HTTPS 網站存取區域 HTTP 相機的 Local Network Access 行為。
8. `tiger-camera.fengyenchia.com` 的 DNS、部署、私人物件儲存、資料庫與登入提供者。
