# Tiger Camera V1 完整產品規劃

## 1. 產品定義

Tiger Camera 是一台帶有角色感的小型玩具相機。虎頭是外殼，方形彩色螢幕藏在虎嘴中；拍照成功後，螢幕會在剛拍好的照片上顯示一則隨機小虎文字。照片先以 JPEG 原圖保存，正式復古後製交由手機網頁處理。

一句話版本：

> 按下虎頭相機的快門，牠會留下照片並在虎嘴螢幕回一句俏皮文字，再讓手機把照片變成一張帶日期、虎圖案與復古質感的數位拍立得。

## 2. 設計目標

1. **好玩先於規格競賽**：虎嘴螢幕、拍後回看與隨機小虎文字形成明確記憶點。
2. **可完成**：ESP32 只做擅長的拍攝、儲存、顯示與區域傳輸；複雜後製放到手機。
3. **離線可用**：不需要 App、帳號或雲端伺服器。
4. **保留原圖**：任何濾鏡都不覆寫 JPEG 原始照片。
5. **先證明核心技術，再做漂亮外殼**。

## 3. 主要使用者流程

### 3.1 拍照

1. 長按電源或喚醒按鍵啟動。
2. 虎嘴螢幕顯示即時預覽。
3. 使用者短按實體快門。
4. 裝置鎖定畫面並拍攝 JPEG。
5. 以原子寫入方式將 JPEG 與同名 JSON 中繼資料存入 microSD。
6. 儲存成功後，螢幕顯示剛拍的照片與一則隨機小虎文字 3～5 秒。
7. 回到即時預覽。

目標體感：

- 從按下快門到畫面凍結：小於 300 ms。
- 從按下快門到可看到成品預覽：小於 2 秒。
- 儲存失敗時不得假裝成功，必須顯示明確提示。
- 隨機文字只在 JPEG 與 JSON 成功保存後顯示；失敗時改顯示錯誤訊息。

V1 拍照成功文字池：

- `ROAR!`
- `抓到你了！`
- `虎視眈眈！`
- `今日獵物 +1`
- `小虎拍到了！`

抽選應近似均勻；同一句不得連續出現兩次。文字應加描邊、底色或陰影，確保在明暗照片上都可讀。

### 3.2 手機下載與後製

1. 手機連接相機 Wi‑Fi：`TIGER-CAMERA`。
2. 系統嘗試自動開啟 Captive Portal。
3. 未自動開啟時，使用者進入 `http://tigercam.local`。
4. 備援入口為 `http://192.168.4.1`。
5. 網站顯示最新照片與相簿。
6. 使用者挑選四款效果之一，或採用相機隨機指定的預設效果。
7. 手機以 Canvas 合成色調、暗角、顆粒、日期、透明圖案與邊框。
8. 使用者下載完成 JPEG 或原圖。

### 3.3 網址的正確定位

- `tigercam.local` 是連上相機 Wi‑Fi 後可使用的 mDNS 名稱，不是公開網站。
- Captive Portal 會攔截一般 HTTP 導覽並帶到相機首頁。
- `tiger.camera` 可作為展示用區域別名，但不應是唯一入口；`.camera` 是真實頂級網域，離線 DNS 攔截、HTTPS 與不同手機行為可能不一致。
- V1 不承諾離線 HTTPS。頁面只在區域網路處理照片，不傳帳密或付款資訊。

## 4. 功能範圍

### 4.1 V1 必做

- 即時相機預覽
- 單一實體快門短按拍照
- JPEG 寫入 microSD
- 拍後回看
- 拍後回看時從 5 句文字中隨機顯示一句
- 方形螢幕置於虎嘴
- Wi‑Fi AP 與 Captive Portal
- 相簿、最新照片與單張照片頁
- 四種手機端復古效果
- 日期、邊框、圖案、顆粒、暗角
- 原圖／完成 JPEG 下載
- USB-C 充電
- 電量與充電狀態提示
- 虎頭 3D 列印外殼
- 錯誤狀態：無 SD、容量不足、拍攝失敗、低電量

### 4.2 V1 明確不做

- GIF 或影片
- 觸控螢幕
- Bluetooth 傳照片
- 專屬手機 App
- 公開雲端網站與帳號
- AI 濾鏡
- 相機端高解析度後製
- 自動上傳社群
- 多台相機互傳

### 4.3 待做清單

- 長按快門進行 2～3 秒動態連拍
- 手機端合成與下載 GIF
- 更多濾鏡與手動參數
- QR Code 直達最新照片
- 相機端相簿瀏覽
- OTA 無線更新
- 更完整的休眠與喚醒
- 每張照片短效權杖與私人瀏覽模式
- 公開網站／雲端備份（僅在真的需要跨網路查看時評估）

## 5. 四款 V1 效果

| 效果 | 視覺配方 | 裝飾 |
|---|---|---|
| Tiger Film | 暖橘、低對比、輕暗角、細顆粒 | 黑細框、虎掌、復古日期 |
| Jungle Green | 綠黃偏色、降飽和、柔和高光 | 葉片角落、白色日期 |
| Baby Tiger | 明亮暖色、淡橘圓角框 | 虎耳／尾巴、ROAR! |
| Night Hunter | 黑白或低飽和、高對比、粗顆粒 | 紅日期、爪痕、強暗角 |

輸出原則：

- 長邊最多維持原圖解析度，不無意義放大。
- JPEG 品質預設 0.9，可切換「高畫質」0.95。
- 後製結果只存在手機下載，不必回寫 SD；未來再評估快取。

## 6. 資料與隱私

V1 預設是「有 Wi‑Fi 密碼的共享相簿」：

- 任何連上 `TIGER-CAMERA` 的人都可能看到相簿。
- Wi‑Fi 使用 WPA2 密碼，不使用公開無密碼熱點。
- 刪除照片需輸入管理 PIN，且 API 必須再次驗證，不只在畫面隱藏按鈕。
- 網站清楚顯示「目前為區域共享相簿」。
- 展示場合每次使用完可由機身選單或管理頁清空相簿。

若作品要讓陌生人使用，應把「QR Code＋單張照片短效權杖」升級為 V1.1 的高優先項目。

## 7. 成功指標

### 功能驗收

- 連續拍 30 張，至少 29 張成功保存且可讀。
- 重新開機後照片與中繼資料仍存在。
- Android Chrome、iPhone Safari、桌面 Chrome 均可進站與下載。
- 四款效果輸出方向、日期與顏色正確。
- 無 SD、SD 滿、相機錯誤與低電量都有可理解提示。

### 體驗驗收

- 第一次使用者在沒有口頭教學時，2 分鐘內完成「連 Wi‑Fi→找到照片→後製→下載」。
- 五句拍照成功文字都能出現，且不連續重複同一句。
- 手持時不遮鏡頭、天線與 USB-C。

## 9. 目前尚未鎖死的決策

以下必須由實測決定，不在紙上假定：

1. microSD 與 ST7789 共用 SPI 是否在目標幀率下穩定。
2. 實際收到的相機感測器型號。
3. 800 mAh 電池的真實續航與峰值電流是否足夠。
4. 最終外殼尺寸與鏡頭／螢幕相對位置。
5. 五句回饋文字在 240 × 240 畫面上的最終字級與排版。
6. iOS 與 Android 的 Captive Portal 行為。
