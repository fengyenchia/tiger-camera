# Hardware

## 已驗證核心

| 項目 | 實機結果 |
| --- | --- |
| 主板 | AroundTW／GOOUUU ESP32-S3-CAM |
| 模組 | ESP32-S3-WROOM-1-N16R8，16 MB Flash、8 MB PSRAM |
| 相機 | OV2640，PID `0x26` |
| 螢幕 | ST7735 SPI，`128x128`；實際吋數與 PCB 外形待量測 |
| 快門 | GPIO1，`INPUT_PULLUP`，按下接 GND |
| 顯示 | `INITR_144GREENTAB`、BGR、inversion off；RGB 色序與方形即時預覽已確認 |
| 拍攝 | 固定 XGA `1024x768`，預覽與拍照色彩一致，使用者已接受 |

先前 VGA→UXGA 切換會讓高解析照片嚴重欠曝，因此已淘汰。V1 不再保留這條執行路徑，使用固定 XGA 讓曝光與白平衡持續收斂。

> 先前的 ST7735 實測紀錄誤以 128×160 初始化。正式韌體現已改為 `INITR_144GREENTAB` 的 128×128 模式；RGB 色序與方形即時預覽已重新確認。之後更改 rotation、tab 設定或面板時，仍需再次驗證可視區偏移、文字位置與拍後回顧。

## 核心接線

- 以正式韌體 `include/app_config.h` 與賣家實際 pinout 為唯一接線依據。
- 不沿用 AI-Thinker ESP32-CAM pinout。
- TFT SPI 線保持短、所有模組共地。
- 快門只短接 GPIO1 與 GND，不外加高電位。
- microSD 是未來選配；V1 原圖上傳雲端，裝置只以 PSRAM 暫存最新 JPEG。

## P0 外接電池方案

### 零件

- 帶保護板的單節 3.7V LiPo；目前候選 803040 800mAh，未購買前不得視為定案。
- 5V 2A／2.4A 單節鋰電池充電、保護、升壓模組。
- 額定電流足夠的實體電源開關。
- JST-PH 2.0 2P 公母線、適合線徑、熱縮管。

賣家標示模組輸入 4.5–5.5V、滿充 4.2V±1%、輸出 5–5.15V、最高 2.4A，並宣稱 OCP／OVP／SCP／OTP。這些都是待量測規格，不代表 2.4A 可長時間連續輸出；標示的最高 2.1A 充電也不能直接套用到 800mAh 電池，必須以電芯 datasheet 為準。

### 接線

```text
LiPo BAT+ / BAT-
        │
        ▼
充電＋保護＋5V 升壓模組
        │ 5V OUT+ / GND
        ▼
實體電源開關（切斷 5V OUT+）
        │
        ▼
ESP32-S3-CAM 5V / GND
```

禁止事項：

- 不把裸 LiPo 直接接主板 `5V` 或 `3V3`。
- 不只看 JST 外殼方向判斷正負極，每一條線都要用萬用電表確認。
- 初次測試時，不同時接主板 USB-C 與升壓模組 5V，避免未知回灌路徑。
- 未確認模組支援 power-path／邊充邊用前，充電時關閉相機。
- 不在麵包板或裸線狀態下無人看管充電。

ESP32-S3 晶片的 3.3V 電源設計需為無線峰值保留裕量；本板由 5V 輸入再穩壓，因此 P0 要實測相機、TFT 與 Wi-Fi TLS 上傳同時工作的壓降，而不是只看空載 5V。參考：[Espressif ESP32-S3 Hardware Design Guidelines](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/schematic-checklist.html)。

### P0 實作流程

1. 收貨拍照並記錄電池尺寸、接頭、極性、初始電壓與電芯規格；量模組尺寸及焊盤標示。
2. 不接主板，檢查短路後量 5V 輸出極性與空載電壓。
3. 用可控負載或 USB 電流表逐步加載，記錄電壓、電流與模組溫度。
4. 主板 USB-C 拔除，升壓輸出經開關接主板 5V/GND；先開機與預覽，再測拍照與上傳。
5. 進行 30 次拍照／上傳，觀察 brownout、重啟、TFT 閃爍、Wi-Fi 失敗與 PSRAM。
6. 測低電量截止、重新充電、關機充電時間與至少一次完整續航。
7. 通過後才決定電池艙、模組固定、開關與充電孔位置。

### 電量顯示

P0 初版只使用充電模組 LED。沒有電池 ADC 分壓或 fuel gauge 時，不在 TFT 顯示百分比、剩餘時間或精確充電狀態。日後若加入量測電路，需重新檢查 GPIO、分壓耗電與校正。

## 外殼限制

- 基本矩形相機，不做虎頭、喇叭或音訊孔。
- 電池周圍保留膨脹與拆修空間，螺絲尖端不得朝向電芯。
- 電池、升壓電感與大面積金屬避開 ESP32 天線區。
- 保留 USB、充電孔、開關、NFC、快門、鏡頭與散熱空間。
- 全部尺寸以卡尺量到的實物為準。
