# 硬體、腳位與外殼規劃

## 1. 模組分工

| 模組 | 職責 |
|---|---|
| XIAO ESP32S3 Sense | 相機、Wi‑Fi、PSRAM、Flash、充電管理 |
| Sense 擴充板 | 相機、microSD 卡槽、數位麥克風（V1 不使用） |
| ST7789 IPS | 即時預覽、拍後照片、隨機文字、狀態與 QR Code |
| 3.7 V LiPo | 可攜式供電 |
| 電阻分壓 | 將電池電壓縮小後送入 ADC |
| 快門按鍵 | 短按拍照；長按保留 |

## 2. 已知官方限制

- Sense 板載 microSD 會占用 SPI 相關腳位。官方文件指出 D8/GPIO7、D9/GPIO8、D10/GPIO9 為 SCK、MISO、MOSI；CS 在不同板版資料中出現 GPIO21 或 GPIO3，必須依實際硬體版號與範例程式確認。
- ST7789 也使用 SPI，因此不能假設兩者直接接上就一定穩定。
- XIAO ESP32S3 沒有直接供韌體讀取的電池量測腳；要顯示百分比，需額外電阻分壓到 ADC。
- 使用電池供電時，XIAO 的 5 V 腳沒有輸出。外接模組不可依賴 5 V rail。
- Sense 的 D11/GPIO42 與 D12/GPIO41 同時是板載數位麥克風腳。V1 不用麥克風，可把其中一腳用於電池 ADC，但需停用麥克風。

## 3. 暫定腳位表

這是「等待麵包板驗證」的配置，不是最終 PCB 定案。

| 功能 | XIAO 腳位 | GPIO | 備註 |
|---|---:|---:|---|
| SPI SCK | D8 | 7 | microSD 與 TFT 共用 |
| SPI MISO | D9 | 8 | microSD 使用；TFT 通常不接 |
| SPI MOSI | D10 | 9 | microSD 與 TFT 共用 |
| microSD CS | 依板版 | 3 或 21 | 先讀板版與官方範例 |
| TFT CS | D1 | 2 | 與 SD 分開 |
| TFT DC | D4 | 5 | 顯示資料／命令 |
| TFT RST | D5 | 6 | 可視模組支援改接系統 reset |
| 快門 | D3 | 4 | INPUT_PULLUP，按下接 GND |
| 電池 ADC | D11 | 42 | 需分壓；停用板載麥克風 |
| 備用 | D0／D6／D7／D12 | 1／43／44／41 | 可供背光 PWM、除錯或未來擴充；V1 不接音訊 |

若實際板版的 SD CS 占用上表腳位，先重排 TFT CS／快門，不改變整體架構。

## 4. SPI 共用策略

優先方案：

1. microSD 與 TFT 共用 SCK、MOSI；SD 另用 MISO。
2. 兩者各自有 CS，任何時間只允許一個 CS 為 LOW。
3. 顯示更新與 SD 寫入透過同一個 mutex／工作佇列序列化。
4. 每個裝置明確設定 SPI transaction 的時脈與模式。
5. 拍照寫檔期間先凍結即時預覽，完成後再顯示縮圖。

退出條件：只要發生無法解釋的 SD corruption、TFT 畫面亂碼或拍攝重啟，就不把共用 SPI 帶入外殼階段。

備援順序：

1. 降低 TFT SPI 時脈並減少全畫面更新。
2. 將 TFT 改為軟體 SPI。
3. 以硬體 reset 共用節省一腳。
4. 最後才更換主板或加 GPIO 擴充，不一開始增加成本。

## 5. 電源設計

### 5.1 供電

- LiPo 接 XIAO BAT 焊盤，由 USB-C 充電。
- ST7789 使用 3.3 V。
- 所有模組共地。

### 5.2 電池量測

建議先用 200 kΩ／100 kΩ 分壓，4.2 V 電池在 ADC 端約 1.4 V；韌體再以萬用電表校正。分壓會持續耗電，若續航不足，可改用更高阻值或 MOSFET 控制量測。

百分比不要只做線性換算；V1 可用分段近似：

- 4.10 V 以上：100%
- 3.90 V：約 70%
- 3.75 V：約 40%
- 3.60 V：約 15%
- 3.45 V 以下：準備關機

這只作 UI 估計，不是精密電量計。

### 5.3 續航預估

官方資料顯示 Sense 網路攝影使用情境約有百餘 mA 平均消耗，拍照瞬間更高；再加螢幕後，800 mAh 仍不應直接宣稱可用 5 小時。

原型目標：

- 連續開機與預覽：先以 1.5～3 小時作保守測試區間。
- 待機：加入降亮度或深睡後再量測。
- 低於 10% 時降低螢幕亮度並限制高耗能操作。

必須用 USB 電流表或量測工具取得實測值後才寫正式續航。

## 6. 外殼設計

### 6.1 結構

- 前殼：虎臉、鏡頭孔、鼻子、嘴部螢幕窗。
- 後殼：快門、電源、USB-C、SD 維修口。
- 內骨架：固定 XIAO、螢幕與電池，不靠熱熔膠承受全部力量。
- 電池艙：不可被螺絲尖端擠壓，保留膨脹空間。

### 6.2 虎嘴螢幕

- 外觀開口做圓角嘴型，內部仍使用方形 1.3 吋模組。
- 第一版先用黑色遮罩框遮住 PCB 與背光漏光。
- 螢幕不得成為承力面，前方可加薄透明保護片。
- 拍後文字需保留安全邊界，虎嘴遮罩不可裁掉字句。

### 6.3 RF 與散熱

- 外接 Wi‑Fi 天線需安裝，並避開電池與大面積金屬。
- 天線前方不要用含金屬顏料或金屬網罩。
- USB-C 必須可直接插拔，不拆殼充電。

### 6.4 外殼設計順序

1. 量實體模組尺寸。
2. 建立粗略 stack-up。
3. 印 1:1 平面定位板。
4. 印只包含鏡頭、螢幕與按鍵的功能殼。
5. 通過手持測試後才雕虎頭細節。

## 7. 不可省略的硬體關卡

### Gate H0：供電安全

- 極性、充電、4.2 V 滿電與 USB 插拔正確。
- 預覽、拍照與寫入時不 brownout。

### Gate H1：核心三件套

- 相機連續取景。
- microSD 連續寫 30 張。
- TFT 更新不導致 SD 錯誤。

### Gate H2：完整麵包板

- 加入快門與電池量測。
- 連拍與 Wi‑Fi 傳輸時無 brownout。

### Gate H3：外殼樣機

- 所有接頭可維修。
- 天線訊號、按鍵手感、文字可讀性與鏡頭遮擋合格。
