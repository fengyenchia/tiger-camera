# P0 電源實作操作手冊

本手冊適用於目前選定的電源組合：

> **Gate P0 已通過。** 2026-08-28 使用者確認本手冊的電源組裝與測試已完成；以下步驟保留作為日後拆修與重組依據。

- 803040、3.7V、1000mAh LiPo 電池
- TP4056 Type-C 1A 充電保護板
- MT3608 可調 5V 升壓板
- KCD1-11 三腳船型電源開關
- DT-830D 數位萬用電表

本方案不支援邊充邊用。充電時只讓 TP4056 工作；使用時拔除 USB-C，再由 MT3608 供電給 ESP32。

## 0. 安全規則

1. 第一次測試一定要有人看著，不要夜間或離開時充電。
2. 電池外皮破損、鼓包、異味、漏液或異常發熱時，立即停止使用。
3. 不要直接焊接裸電芯的金屬極耳，只焊接電池原本引出的導線或保護板輸出端。
4. 不要把電表的電流檔並接在電池兩端；電流檔只能串接，否則會造成短路。
5. 不要同時接 ESP32 的 USB-C 與 MT3608 的 5V 輸出。
6. 未確認 MT3608 輸出前，絕對不要接 ESP32。

## 1. 收貨檢查

準備：DT-830D、十字螺絲起子、烙鐵、焊錫、熱縮管、絕緣膠帶、5V/2A USB 充電器。

逐項確認：

- 電池型號 803040，尺寸約 8 × 30 × 40mm。
- 電池導線有紅／黑標示；紅線通常是正極、黑線通常是負極，但仍要用電表確認。
- TP4056 有 `IN+ / IN-`、`B+ / B-`，若有 `OUT+ / OUT-` 也記錄下來。
- MT3608 有 `IN+ / IN-`、`OUT+ / OUT-` 與可調電位器。
- KCD1-11 的三個腳位沒有鬆動；三腳版本先不要依外觀猜腳位。

本批板子的端子以實物絲印為準：

- TP4056：`IN+ / IN-` 是 USB 5V 輸入；`B+ / B-` 接電池；`OUT+ / OUT-` 接負載（MT3608）。照片可見 `TC4056A` 充電 IC 與保護區，但充電電流仍以實測為準。
- MT3608：`VIN+ / VIN-` 是輸入；`VOUT+ / VOUT-` 是輸出。賣家標示輸入 2–24V、最大輸出 2A、效率約 93%，2A 是最大標稱值，不代表本板可長時間輸出 2A。
- KCD1-11：賣家標示 3A/250V、6A/125V；三腳版本的第三腳可能是指示燈或不同接點，必須用通斷檔確認。

## 2. DT-830D 基本操作

### 量直流電壓

1. 黑表筆插 `COM`。
2. 紅表筆插 `VΩmA`。
3. 旋鈕轉到 `DCV 20V`。
4. 黑表筆接負極、紅表筆接正極。

### 量通斷／確認開關腳位

1. 電路必須完全斷電，不能接 USB 或電池。
2. 旋鈕轉到通斷蜂鳴檔。
3. 依序碰觸 KCD1-11 的兩兩腳位。
4. 撥到 ON 時會導通的兩腳，就是電源開關的兩端；第三腳先不接。

### 量電流

1. 黑表筆插 `COM`。
2. 紅表筆先插 `10A` 插孔。
3. 旋鈕轉到 `DCA 10A`。
4. 必須切開原本的一條電流路徑，讓電表接在中間。
5. 測完立刻把紅表筆插回 `VΩmA`，避免下次量電壓時短路。

## 3. 先確認 TP4056 電池接線

先不要接 MT3608，也不要接 ESP32。

```text
803040 紅線 → TP4056 B+
803040 黑線 → TP4056 B-
```

如果板子有 `OUT+ / OUT-`，之後讓 MT3608 從 `OUT+ / OUT-` 取電；若沒有，依板上標示從電池端取電。不要把 `IN+ / IN-` 接到電池。

直焊步驟：

1. USB-C 不可插入。
2. 先剪短、剝線、套上熱縮管，但不要先加熱收縮。
3. 紅線焊正極、黑線焊負極。
4. 分別收縮熱縮管，再用膠帶固定導線，避免拉扯焊點。

## 4. 第一次確認 TP4056 充電

803040 的標準充電是 500mA，最大充電是 1A。TP4056 商品標示 1A，因此可以先使用預設值，但第一次必須量測。

### 4.1 量充電電流

1. TP4056 已接電池，但 MT3608 與 ESP32 都不要接。
2. 在 TP4056 電池正極支路製造一個斷點。
3. DT-830D 設為 `DCA 10A`，紅表筆插 `10A`，把電表串接回斷點。
4. 接上 5V/2A USB 充電器。
5. 觀察初期電流：不可超過 1A。
6. 若超過 1A、電流劇烈跳動、電池或 TP4056 明顯發熱，立刻拔除 USB。

若不熟悉串接電流量測，可以先不要量電流，改買商品明確標示「500mA 固定充電」的 TP4056 版本；不要用 USB 電源供應器的額定電流代替充電限流。

### 4.2 第一次充電觀察

- 充電前先記錄電池外觀與電壓。
- 每 5–10 分鐘摸外殼溫度；溫熱但不燙是可接受的，燙手就停止。
- 充電完成後拔除 USB，等待 5 分鐘再進行下一步。
- 充電期間不要接 ESP32，也不要把 MT3608 開關打開。

### 4.3 TP4056 發熱判斷

TP4056 是線性充電器；若以接近 1A 充電，輸入 5V 與電池約 3.7–4.2V 的差額會在晶片上變成熱。這種發熱不等於電池已充滿。電池接近 4.2V 且充電完成時，電流應逐漸下降，TP4056 也應降溫。

若晶片在接上 USB 後很快變得燙手：

1. 立即拔除 USB，關閉 KCD1-11，等待完全冷卻。
2. USB 拔除時，用 `DCV 20V` 量 `B+ / B-`；約 4.15–4.20V 才表示接近充滿，3.7V 左右是正常標稱電壓。
3. 重新充電時保持 ESP32 與 MT3608 斷電，觀察 CHARGE／DONE LED。
4. 若仍在 1–2 分鐘內燙到無法觸碰，不要繼續使用 1A 設定；改用預設 500mA 的 TP4056 板或請賣家更換低電流版本。

電池「已滿」的判斷不能只靠溫度，必須同時看電池端電壓、LED 狀態與充電電流。不要用電腦 USB 的額定電流來硬限制 TP4056。

## 5. 調整 MT3608 到 5.0V

1. TP4056 的 USB-C 必須拔除。
2. 由 TP4056 `OUT+ / OUT-` 接到 KCD1-11，再接 MT3608 `IN+ / IN-`。
3. KCD1-11 打開；MT3608 `OUT` 暫時不要接 ESP32。
4. DT-830D 設為 `DCV 20V`，量 MT3608 `OUT+` 與 `OUT-`。
5. 用小螺絲起子，每次只轉很小角度，調到 `5.0V` 左右。
6. 關閉 KCD1-11，確認輸出不會繼續供電。

```text
TP4056 OUT+ → KCD1-11 共用／輸入腳
KCD1-11 切換腳 → MT3608 IN+
TP4056 OUT- → MT3608 IN-
MT3608 OUT+ / OUT- → ESP32 5V / GND
```

三腳 KCD1-11 的第三腳依版本可能是指示燈端，未確認前保持不接。

若 MT3608 上電後電位器完全無法調整，依賣家說明先斷電，再將電位器逆時針旋轉約 10–15 圈作為初始化，重新上電後再用 DT-830D 調整；不要在未量測時直接接 ESP32。

## 6. 接上 ESP32 的第一次測試

1. 確認 MT3608 空載輸出約 5.0V。
2. 關閉 KCD1-11。
3. 將 MT3608 `OUT+` 接 ESP32 `5V`，`OUT-` 接 `GND`。
4. 拔除 ESP32 的 USB-C，避免雙重供電。
5. 開啟 KCD1-11。
6. 觀察螢幕、相機預覽、快門、Wi-Fi 與上傳。
7. 若 ESP32 重開機、螢幕閃爍、畫面變白或 MT3608 明顯發熱，立即關閉開關。

先完成 3–5 次拍照／上傳，再進行 30 次連續測試。記錄：

- MT3608 輸出是否掉壓
- ESP32 是否 brownout 或重啟
- 螢幕是否閃爍／變白
- Wi-Fi 上傳是否失敗

## 6.1 P0.1：接上電壓與百分比顯示

> **驗收狀態：已通過。** 2026-08-28 使用者完成實機接線、校正與顯示確認。

完成第 6 節、確認相機可正常拍照與上傳後，才加入這一小段量測線。這是**電壓推估**，不是精準電量計。

需要：2 顆 100kΩ 電阻與一條接到 GPIO3 的細導線。0.1µF 陶瓷電容是選配；可以先不裝，讀值可能稍微跳動。

```text
TP4056 OUT+ → KCD1-11 → 分支 A → MT3608 IN+
分支 A → 100kΩ → GPIO3
GPIO3 → 100kΩ → TP4056 OUT-／MT3608 IN-／ESP32 GND
選配：GPIO3 → 0.1µF 陶瓷電容 → GND
```

1. 關閉 KCD1-11、拔掉 TP4056 USB-C 和 ESP32 USB-C。
2. 先焊兩顆電阻，確認中點只接 GPIO3；上方 100kΩ 必須接在 KCD1-11 開關後方，不要直接接常時帶電的 TP4056 `OUT+`。
3. 再確認一次：GPIO3 **沒有**直接接 `OUT+`、5V 或電池正極。
4. 開機，TFT 右下角應顯示 `x.xxV yy%`；剛接好時可先看到 `BAT --`，表示韌體尚未取得合理電壓。
5. DT-830D 設為 `DCV 20V`，量 TP4056 `OUT+ / OUT-`；和螢幕電壓比較。相差超過約 0.05V 時，先停機並檢查兩顆電阻值、焊點與共地；確認無誤後才微調 `batteryVoltageCalibration`。
6. 連續冷啟動 10 次，再各做拍照、Wi-Fi 上傳與關機／開機測試。GPIO3 是 ESP32-S3 的啟動設定腳位；若發生任何無法開機、USB 異常或重啟，先移除 GPIO3 分壓線。

相機開機時，100kΩ＋100kΩ 的固定耗電約 21µA（滿電 4.2V 時），相對 1000mAh 電池很小；關機時由 KCD1-11 一併切斷。選配的 0.1µF 陶瓷電容可降低高阻抗 ADC 的抖動。

## 7. 充電與使用的日常流程

### 充電

1. 關閉 KCD1-11。
2. 確認 ESP32 的 USB-C 已拔除。
3. 將 5V/2A USB 充電器接到 TP4056 USB-C。
4. 充電完成後拔除 USB-C。

### 使用

1. 確認 TP4056 USB-C 已拔除。
2. 開啟 KCD1-11。
3. 使用相機。
4. 長時間不用時關閉 KCD1-11。

## 8. 何時才做外殼

以下測試全部通過後才固定零件與開孔：

- 充電電流不超過 1A。
- 充電時電池與 TP4056 沒有異常升溫。
- MT3608 空載輸出穩定在 5.0V。
- ESP32、TFT、相機與 Wi-Fi 同時工作不重啟。
- 30 次拍照／上傳測試通過。

外殼需預留：USB-C 充電孔、KCD1-11 矩形孔、MT3608 電位器與測試接點；電池周圍保留膨脹與維修空間，並用絕緣片隔開電路板焊點。

## 9. 立即停止條件

出現以下任一情況，拔除 USB、關閉開關，不要繼續測試：

- 電池鼓包、漏液、異味或燙手。
- TP4056 晶片燙到無法觸碰。
- 充電電流超過 1A。
- MT3608 輸出超過 5.2V 或不穩定跳動。
- ESP32 反覆重啟或出現焦味。
